# fable5-mind 効果測定ハーネス

fable5-mind スキルの効果を**プログラム採点で数値化**するための A/B 評価
ハーネスと、その実測結果です。LLM による主観採点は使わず、すべての
アサーションはコードで判定します。

## 構成

```
eval/
  tasks/         # 標準タスク8件(バグ修正・複合指示・スコープ・罠・検証・リネーム)
  tasks-hard/    # 高難度タスク6件(誤前提誘導・埋め込み指示・偽前提質問・
                 #   docstring契約・厳密フォーマット・複数箇所整合)
  aggregate.py   # 採点集計スクリプト
  results/       # 実測結果(JSON + Markdownレポート)
```

各タスクは `workspace/`(エージェントが操作するファイル)、`prompt.txt`
(両アーム共通のタスク文)、`grade.py`(採点スクリプト、
`python grade.py <workspace>` で JSON を出力)から成ります。

## 測定方法

- **アーム**: skill(プロンプト冒頭で SKILL.md の遵守を指示)/ control
  (同一タスク文のみ)。タスク文は完全に同一。
- **実行**: 各タスクのワークスペースをアームごとに複製し、独立した
  エージェント(1タスク1エージェント)に実行させる。
- **採点**: エージェント終了後に `grade.py` で機械採点し、`aggregate.py`
  で集計。
- **ハーネス自己検証**: 未修正ワークスペースで「バグ系アサーションのみ
  FAIL」、模範解答適用後に「全アサーション PASS(標準30/30・高難度21/21)」
  を確認済み。

## 実測結果(2026-07-07、モデル: Claude Haiku 4.5、n=1/セル)

### 精度

| タスクセット | アサーション合格率(skill) | 同(control) | タスク完全合格 |
|---|---|---|---|
| 標準8タスク(30アサーション) | 30/30 (100%) | 30/30 (100%) | 8/8 vs 8/8 |
| 高難度6タスク(21アサーション) | 21/21 (100%) | 21/21 (100%) | 6/6 vs 6/6 |
| **合計(51アサーション)** | **51/51 (100%)** | **51/51 (100%)** | 14/14 vs 14/14 |

**両アームとも天井(ceiling)に到達し、この規模のタスクでは精度差は検出
されませんでした。** 高難度セットの罠(「バグは parser.py にあるはず」
という誤誘導、存在しないAPIを前提にした質問、括弧書きで埋め込んだ副次
タスク等)も、control アームの Haiku 4.5 がすべて自力で回避しています。

### コスト(効率)

|---|---|---|---|
| トークン(標準) | 216,896 | 172,574 | +25.7% |
| トークン(高難度) | 164,441 | 129,456 | +27.0% |

## 解釈と限界

1. **ツールアクセスを持つ現行世代モデルは、明確に仕様化された自己完結の
   小タスクにおいて、スキルなしでも証拠優先の行動を既に取る。** 前身
   プロトコルで報告されていた「60% vs 40%」の差は、本タスク規模では
   再現されなかった。
2. この規模では**スキルの測定可能な効果はコスト増(トークン+26%前後)
   のみ**である。明確な小タスクにはスキルを起動しない(SKILL.md の
   タスクサイズ判定で S 扱いにする)のが合理的。
3. **本測定で否定できないこと**: 長時間・多ファイル・要件が曖昧な実務
   タスク(制約の取りこぼしやスコープドリフトが実際に起きる領域)、
   ツールを持たない設定、より旧世代・小型のモデルでの効果。クリーンな
   マイクロベンチマークは、規律の足場が最も効きにくい条件である。
4. n=1/セル。差がゼロの結論は 51 アサーション×2アームの一致に基づくが、
   非決定性による揺らぎを完全には排除していない。

## 再現手順

1. ワークスペースを複製: `eval/tasks*/<task>/workspace` を
   `<runs_root>/<task>-{skill,control}/workspace` にコピー。
2. 各セルをエージェントに実行させる。skill アームのみ、プロンプト冒頭に
   「`.claude/skills/fable5-mind/SKILL.md` を読み、その指示に完全に従う
   こと」を追加。タスク文は `prompt.txt` を両アームで共通使用。
3. 集計: `python eval/aggregate.py <runs_root> <out_dir> [eval/tasks-hard]`
4. `results.json` / `report.md` が出力される。

- セッション途中でのコンテキスト圧縮を伴う長時間タスク
- 複数トライアル(n≥5/セル)による分散の測定
